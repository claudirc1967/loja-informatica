# Loja de Equipamentos de Informática

Sistema completo de e-commerce para venda de equipamentos de informática desenvolvido em Node.js com armazenamento local em JSON.

## Funcionalidades

- ✨ Catálogo de produtos com imagens
- 🛒 Cesta de compras
- 💳 Simulação de pagamento (PIX e Cartão de Crédito)
- 💾 Armazenamento local em JSON
- 🎨 Interface moderna e responsiva

## Instalação

```bash
npm install
```

## Execução

```bash
npm start
```

O servidor estará rodando em `http://localhost:3000`

## Estrutura do Projeto

- `server.js` - Servidor Express e rotas da API
- `data/` - Armazenamento JSON (produtos, carrinho, pedidos)
- `public/` - Frontend (HTML, CSS, JavaScript)
- `images/` - Imagens dos produtos
